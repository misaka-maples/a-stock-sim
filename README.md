# A股日线模拟交易与研究系统

默认交易入口已改为两个日线动量策略：`Momentum_Rotation_Pro` 与 `Momentum_Rotation`。
这两种策略共用 `strategy_rules.py`；旧版突破、共振等策略仍为独立实验规则，不能据其日线近似结果推断实时盘口收益。

## 数据与交易

历史指标使用前复权日线；成交、整手和现金账务使用原始价格。信号只读取已完成交易日数据，在下一交易日执行。模拟服务使用到达时的有效五档盘口；回测以次日原始开盘价、滑点与日量容量近似，二者执行价格可能不同。

历史请求默认截至北京时间上一完整交易日（交易日15:05后允许当日）。策略准备在后台线程执行，覆盖整个配置股票池及已有持仓，没有前100只限制。接口 `/api/status` 的 `data_quality` 显示有效覆盖、截止日期、缺失数据和行业覆盖。开仓需要新鲜、无请求错误的历史数据及足够的实际日线；停牌、IPO或旧窗口缺口保留诊断，不会清空已有持仓的有效止损证据。历史及行业数据来自公开接口，不填造缺失日线。

实时成交必须有同日且120秒内的时间戳、合法对手盘口、成交量和价格；按照五档深度与成交参与率限制容量，支持部分成交。同一时间戳与每日累计容量持久化，重启不会补回已消耗的容量。限价单只撮合满足限价的档位，未成交部分不自动挂成真实交易所订单。

账户保持T+1；日线止损是出场信号，不能保证亏损止于该百分比。昨日收盘触发的退出意图会保留至可成交或清仓，不因缺日线或隔日价格回升自动丢失。

## 仓位与轮动

`MomentumConfig` 支持单股上限、单笔风险预算、ATR/波动率调整、行业上限、5交易日轮动、排名缓冲、最低持仓期和止损后冷却期。每次新买同时检查现金与行业容量。行业缺失的股票合并至“未知行业”，同样受行业上限约束。上限用于新增仓位，并不会即时强卖价格上涨或旧配置造成的超配仓位。

默认新配置为6只、单股20%、风险预算1%、止损信号−6%、行业35%；启动时优先读取已有策略配置，保留原账户、持仓与参数。新增风险预算会进一步约束新增仓位，风险预算与止损距离只是模型估计。

`POST /api/strategy/config` 可更新风险和轮动字段；`POST /api/strategy/switch` 可切换规则。配置会持久化。固定历史收益宣传已移除，策略卡片显示“待验证”。

`sim_account.json` 追加完整成交、日度净值、长期回撤状态、待执行意图和容量记录；快照恢复会保留这些字段。每笔成交的账务、容量、最终状态及策略意图一次写入并同步磁盘，成功后才触发通知。写盘失败会回滚并停止交易，修复存储后重启。成本以分记账，展示均价不参与盈亏计算；完整旧流水可重建成本和盈亏归因，并保留被修正的 `legacy_realized_pnl`，不改变现金、股数及成交数量。无法重建的成本标记估计值。旧账户无法补回已丢失的净值历史，也不再从成交填造历史收盘权益。

新增买入按实际成交均价、费用及成交后权益复核单股和行业预算，必要时缩减到整手；同一时间戳的盘口增量不会补充最初容量。历史ST涨跌幅按交易日期选择规则，交易所明确涨跌停价优先，仍禁止买入风险警示股票。2026年7月6日规则调整依据：[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[深交所风险警示板通知](https://www.szse.cn/lawrules/service/member/t20260630_621404.html)。

## 启动与验证

```bash
./start.sh
./status.sh
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest -q
```

网页首次访问需要登录。服务默认保护所有 `/api` 管理、账户及导出接口；仅登录、认证状态和 `/health` 可匿名访问。同源浏览器使用 HttpOnly、SameSite=Strict 会话，8小时或重启后重新登录；删除开放CORS，写请求检查来源。首次启动生成独立密码及API令牌，保存在 `data/private/api_credentials.json`（目录700、文件600），不复用SSH密码。可通过SSH在服务器读取此文件；程序接入使用 `Authorization: Bearer <api_token>`。凭据文件不进入Git或快照导出。通知配置和快照创建响应只展示脱敏配置；认证后下载的整机迁移包仍含通知凭据，请作为私有备份保存。

快照ID和标签只接受字母、数字、下划线与短横线；不允许路径或符号链接。归档恢复只读取白名单的普通文件，不解压任意路径。恢复先验证策略参数，再写盘和重载；出错会回滚。配置刷新间隔限定1至60秒，持久化股票池和间隔，参与率立即同步账户执行器。后台健康检查包含线程和存储状态，收盘归档在取得有效最终行情后执行。

默认测试全部离线。行情与长期历史集成测试只在显式设置 `RUN_MARKET_INTEGRATION=1` 时执行；通知测试永久mock，不发送消息。`ledger_only=True` 只供独立账务单元测试，服务和策略执行默认必须经过撮合验证。

## 消融、仓位与样本外研究

```bash
python3 research.py --network \
  --train 2024-01-01 2024-12-31 \
  --validation 2025-01-01 2025-12-31 \
  --holdout 2026-01-01 2026-10-13 \
  --output data/research/report.json
```

也可用 `--fixture market_fixture.json` 或 `--data-dir historical_data` 离线运行。数据目录含 `benchmark.json` 及 `stocks/<symbol>.json`，每只股票含 `bars`；指标OHLC之外须有 `raw_open/raw_close/raw_high/raw_low/adjustment_factor`。`--industry-map` 接收股票至行业映射，`--universe` 接收每只股票当时有效资格区间。

默认16个方案：3/5/6/8只持仓 × 基础动量/MA120/高位过滤/风险调整。训练集排序，验证集选择一个冻结规则，留出集只评价该规则一次。费用2倍、滑点2倍/5倍压力在验证区间评价冻结规则，不用留出集调参。报告包含净收益、最大回撤、超额收益、换手、仓位、行业暴露和数据覆盖。

滚动验证使用 `--walk-forward-folds folds.json --holdout START END`，不再指定train/validation参数。folds格式为 `[{"train":["START","END"],"validation":["START","END"]}, ...]`，验证窗口不重叠且全部早于最终留出区间。不要在读过最终留出结果后再次据该区间选规则。

此前工程检查报告保存在 `data/research/research_smoke_20261013.json`，使用16只固定主板研究股，训练2024年、验证2025年、留出2026年至10月13日。该报告生成于本次成交、数据及回测修复之前，已标记 `implementation_status.status=superseded`，只保留追溯用途，不作为修复版本的验证，也不再据已观察的留出区间调参。历史股票池资格与行业快照时点未核实，分红、送股及退市现金回收事件尚未记账。企业行动、停牌和执行近似的限制会随报告返回。ETF尚不在主板撮合模型支持范围内。
