# A股定时运行模拟交易系统 (Paper Trading System)

参考 `/home/maple/a_stock_final.py` 与 `/home/maple/a_stock.py` 的实时行情抓取与多指标复核方法，构建的高拟真度、可定时调度、支持 Web 控制台与 HTTP 接口长期常驻运行的 A 股模拟交易策略框架。

---

## 核心架构特性

1. **高速实时盘口获取**：
   - 接入腾讯实时行情与五档盘口（`qt.gtimg.cn`），批量获取股票当前价、昨收、今开、涨跌幅、最高/最低、成交额、成交量及买卖五档挂单。
   - 包含数据新鲜度校验（`fresh`）与交易状态识别（`早盘交易中`、`午盘交易中`、`午间休市`、`节假日/周末` 等）。

2. **A股拟真实战规则**：
   - **T+1 交易制度**：当天买入的股票自动冻结，次日交易日自动解冻为可卖出持仓（支持 `--no-t1` 参数用于盘外即买即卖测试）。
   - **整手交易**：买入委托严格遵循 100 股整数倍（1手起）。
   - **真实规费核算**：
     - 券商佣金：万分之 2.5（最低 5 元）；
     - 卖出印花税：万分之 5（0.05%，仅卖出收取）；
     - 双向过户费：十万分之一（0.001%）。
   - **盘口滑点撮合**：
     - 市价买入：按卖一档（`ask1`）价格撮合；
     - 市价卖出：按买一档（`bid1`）价格撮合；
     - 涨跌停板限制拦截（涨停无法买入，跌停无法卖出）。

3. **HTTP 服务与单页 Web 控制台**：
   - 基于 `FastAPI` + `Uvicorn`，提供现代化 Web 可视化仪表盘；
   - 包含资产走势、持仓盈亏、实时盘口、快捷手动买卖下单、策略启停与重置功能；
   - 自动生成交互式 REST API 文档（`http://127.0.0.1:8000/docs`）。

4. **后台常驻守护与长期运行**：
   - 配套 `start.sh`（后台运行）、`stop.sh`（优雅退出）、`status.sh`（状态巡检）脚本；
   - 提供 `a_stock_sim.service` 配置模板，支持作为系统 systemd 服务随开机自启。

5. **状态持久化与可视化**：
   - 账户资金、持仓明细、历史委托与成交流水实时持久化至 `sim_account.json`，随时重启、随时恢复。
   - 同时支持 Rich 终端仪表盘与 Web 页面双通道查看。

## 全A股市场监控与共振策略特性

1. **全市场覆盖（严格物理剔除科创板）**：
   - 自动生成并验证沪市主板、深市主板、创业板、北交所全量有效股票（5,260+ 只）。
   - 严格物理排除所有以 `688` 开头的科创板代码（`sh688*` / `sz688*`），规避高波动门槛标的。
   - 自动过滤风险警示标的（ST / *ST / 退市 / PT）与长期无成交停牌股票。

2. **超高速多线程并发分片获取**：
   - 将全市场 5,260 只标的分片打包（每批 200 只），通过 `ThreadPoolExecutor(max_workers=16)` 并发直连腾讯高速行情源。
   - **全量 5,260 只股票五档盘口与行情数据刷新仅需 1.2~1.5 秒**。

3. **超短线量价与五档委比共振起爆策略 (ShortTermResonance)**：
   - **多维度信号初筛**：涨幅处于适度起爆区间（`+2.0% ~ +5.5%`）+ 分时强势突破（`现价 >= 今开盘`）+ 卖一档正常挂单；
   - **盘口微观承接**：五档买卖比率（买五档委托量 / 卖五档委托量）$\ge 1.5$；
   - **共振评分与全市场择优排序**：
     $$\text{Score} = \text{委比} \times 1.5 + \left(\frac{\text{涨幅}}{5.0}\right) \times 1.0 + \left(\frac{\min(\text{成交额}, 50000)}{10000}\right) \times 0.5$$
     每轮扫描自动将数百只起爆标的按质量打分排序，优先买入评分最高的领涨标的。
   - **三重动态风控**：硬性止损（-2.0% 立即平仓）+ 动态追踪止盈（盈利达 +3.5% 后，自盘中峰值回撤 1.5% 立即止盈锁利）+ 极端暴涨止盈（+7.0% 直接清仓）。

## 长期后台运行指南 (推荐)

### 1. 启动后台守护服务
```bash
# 进入目录并启动后台服务（默认端口 8000，带 --test 允许非交易时段全天候调试）
./start.sh --test

# 自定义端口和刷新间隔（例如 8080 端口，每 2 秒刷新）
./start.sh --port 8080 --interval 2 --test
```

## systemd 开机自启配置 (可选)

如需系统重启后自动启动模拟交易服务：
```bash
# 复制服务配置文件
sudo cp a_stock_sim.service /etc/systemd/system/

# 重载并启用自启
sudo systemctl daemon-reload
sudo systemctl enable a_stock_sim
sudo systemctl start a_stock_sim

# 查看状态
sudo systemctl status a_stock_sim
```
